Datenschutzerklärung

Diese Anwendung ist eine private Installation von rclone auf einem
Raspberry Pi im Haushalt des Betreibers. Sie wird ausschließlich vom
Betreiber selbst genutzt.

Verarbeitete Daten: Die Anwendung lädt Sicherungskopien der eigenen
Geräte in das Google-Drive-Konto desselben Betreibers hoch. Sie verwendet
die Berechtigung drive.file und hat damit ausschließlich Zugriff auf
Dateien, die sie selbst angelegt hat.

Weitergabe: Es findet keine Weitergabe an Dritte statt. Es gibt keine
Server des Betreibers, keine Analyse und kein Tracking. Die Daten werden
vor dem Hochladen lokal verschlüsselt.
